# Matrix Calculator: Linear Algebra in Python

A Python matrix calculator that implements core linear algebra operations from scratch, without external libraries.

## Tech Stack
Python

## Highlights
- Matrix addition, subtraction, and multiplication with dimension validation.
- Operations implemented manually to show the underlying math.
- Simple interactive console interface.
